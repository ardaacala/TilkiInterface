# TilkiCraft UI v3 – derived parts

Generated by `tools/BuildUiV3.java`. Positions are GUI pixels; font textures are 2 texels per GUI pixel, widget sprites 1x. Sources in `art/source` are read only.
Nothing here has been tested in a running Minecraft client; previews are simulations of the vanilla layout code.
